$LAWLESS

A single-file launcher that connects directly to the verified MotionMemeFactory on HyperEVM. It reads the factory state live, checks the fee and pause status, estimates the real launch transaction, then lets your wallet sign the factory call.

Launch Configuration

This launcher creates the token with no initial buy. Only the factory's live launch fee is sent. The deadline is generated automatically at signing time.

What Preflight Checks

    

      ✓ Chain ID is 999

      ✓ Factory is not paused

      ✓ Live launch fee is readable

      ✓ Name/symbol/metadata byte limits

      ✓ Wallet HYPE balance

      ✓ createToken() gas estimation succeeds

      ✓ No locally tracked launch transaction is still pending
    


    


    
Pending Transaction Rule

    
If your launch is pending, do not click launch again. Use your wallet's Speed Up / Replace function with the same nonce. A second fresh launch transaction can create a duplicate token.
